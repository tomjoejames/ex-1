# Ex 1 – Biodata Using Basic HTML Tags

A personal biodata page built only with basic HTML tags: headings, paragraphs, tables, lists (ordered/unordered), images, links, address, horizontal rules and text-formatting tags.

## Run on Windows (one click)

Double-click **`setup.bat`**. It opens `index.html` in your default browser.
No installs needed – this exercise uses only HTML, CSS and JavaScript.

## Run anywhere else

Open `index.html` in any modern browser.
